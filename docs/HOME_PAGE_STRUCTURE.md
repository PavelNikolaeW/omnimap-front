# Home Page Structure (Exocortex Entry Point)

Структура начальной страницы экзокортекса — точка входа в систему управления знаниями.

## Принципы

1. **Экзокортекс — это не хранилище, а рабочая память**
   - Начальная страница отвечает на "что сейчас актуально?", а не "где что лежит?"

2. **Минимальная когнитивная нагрузка на входе**
   - Пользователь открывает приложение в контексте (задача, мысль, срочность)
   - Интерфейс быстро направляет к нужному

3. **Персональное + Коллаборативное**
   - Чёткое разделение "моё пространство" и "общие пространства"

## 6 блоков верхнего уровня

| # | Блок | Тип | Описание |
|---|------|-----|----------|
| 1 | **Inbox** | Контейнер | Точка захвата — сюда падает всё новое |
| 2 | **Focus** | Контейнер | Текущий контекст, закреплённые блоки |
| 3 | **Projects** | Контейнер | Активные проекты с конечной целью |
| 4 | **Spaces** | Навигация | Ссылки на расшаренные пространства |
| 5 | **Areas** | Навигация | Долгосрочные области ответственности |
| 6 | **Archive** | Навигация | Завершённое, скрыто по умолчанию |

### Inbox (Входящие)

**Цель:** Единая точка захвата мыслей, задач, информации.

- Снижает когнитивную нагрузку — не нужно думать "куда это положить"
- Периодическая разборка и раскладывание по местам
- Может быть расшарен для получения задач от других

**Поведение:**
- Быстрое создание блока (hotkey с любого экрана)
- Показывает количество неразобранных элементов
- Пользователь сам решает кому дать права на добавление

### Focus (Фокус)

**Цель:** Ответ на "над чем я сейчас работаю?"

- Не список из 50 задач, а 1-3 блока текущего контекста
- Закрепление вручную ("сейчас занимаюсь этим")
- В будущем: авторотация ссылки на текущую неделю из календаря

**Планируемая фича — Авторотация:**
```javascript
// Ссылка хранит правило, а не статичный blockId
{
    type: 'autorotate',
    rule: 'currentWeek',
    sourceBlockId: 'calendar-uuid'
}
```

### Projects (Проекты)

**Цель:** Активные инициативы с конечной целью и дедлайном.

**Характеристики:**
- Имеют начало и конец
- Требуют действий
- Личные или командные

**Примеры:**
- "Запустить новую версию продукта"
- "Переезд в новую квартиру"
- "Подготовить презентацию"

### Spaces (Пространства)

**Цель:** Точки входа в коллаборативные зоны.

- Команды, семья, сообщества
- Показывает shared-блоки где есть активность
- Уведомления об изменениях других
- Разграничение контекстов (работа / личное)

**Визуальное отличие расшаренных блоков:**
- Рамка у верхнего расшаренного блока

### Areas (Области)

**Цель:** Долгосрочные сферы ответственности без дедлайна.

**Отличие от проектов:**
- Проект: "Сделать ремонт в ванной" (конечен)
- Область: "Дом" (поддерживается всегда)

### Archive (Архив)

**Цель:** Завершённые проекты, устаревшая информация.

- Не удаляется, но не мешает
- Свёрнут по умолчанию
- Поиск работает и здесь

## 8 Areas (Областей ответственности)

Готовый набор для старта. Пользователь может изменить под себя.

| # | Иконка | Название | EN | Описание | Подобласти |
|---|--------|----------|-----|----------|------------|
| 1 | 🧠 | **Я** | Self | Личность, развитие, смыслы | Здоровье, Развитие, Ментальное, Ценности |
| 2 | 👥 | **Отношения** | Relationships | Люди в жизни | Семья, Друзья, Сообщества |
| 3 | 💼 | **Работа** | Work | Профессиональная деятельность | Карьера, Навыки, Нетворк |
| 4 | 💰 | **Финансы** | Finance | Деньги и активы | Доходы, Расходы, Накопления, Долги |
| 5 | 🏠 | **Среда** | Environment | Окружающая среда | Дом, Вещи, Цифровое |
| 6 | ⚡ | **Энергия** | Energy | Ресурсы организма | Сон, Питание, Движение, Отдых |
| 7 | 🎨 | **Творчество** | Creation | Творчество и хобби | Хобби, Проекты для души |
| 8 | 🌍 | **Мир** | World | Связь с миром | Позиция, Вклад, Экология |

### Почему такое деление

| Область | Зачем отдельно |
|---------|----------------|
| **Self** | Фундамент — без себя нет остального |
| **Relationships** | Люди — отдельная категория ответственности |
| **Work** | Занимает много времени, требует структуры |
| **Finance** | Специфичная область, свои инструменты |
| **Environment** | Физический и цифровой контекст жизни |
| **Energy** | Часто игнорируется, но критично для всего |
| **Creation** | Не работа, не обязанность — важно выделить |
| **World** | Связь с чем-то большим, смысл |

## Автоматическая инициализация (Onboarding)

При регистрации нового пользователя Home Page создаётся автоматически.

### API Endpoints

```
GET  /api/v1/onboarding/status/  → {"onboarding_completed": false}
POST /api/v1/onboarding/status/  → помечает onboarding завершённым
```

### Flow

```
Регистрация → InitUser event → initUser()
                                    ↓
                          checkAndInitializeOnboarding(rootBlockId)
                                    ↓
                          GET /onboarding/status/
                                    ↓
                    ┌───────────────┴───────────────┐
                    │                               │
          onboarding_completed: true    onboarding_completed: false
                    │                               │
                  (skip)              initializeHomePage(rootBlockId)
                                                    ↓
                                      importBlocks([14 блоков])
                                                    ↓
                                      UpdateDataBlock с layoutCells
                                                    ↓
                                      POST /onboarding/status/
                                                    ↓
                                            ShowBlocks
```

### Ключевые файлы

| Файл | Назначение |
|------|------------|
| `src/js/services/homePageInitializer.js` | Генерация и создание структуры |
| `src/js/api/api.js` | API методы `getOnboardingStatus()`, `completeOnboarding()` |
| `src/js/stateLocal/localStateManager.js` | Интеграция в InitUser event |

### Что создаётся

При onboarding создаётся **14 блоков**:
- 6 блоков верхнего уровня (Inbox, Focus, Projects, Spaces, Areas, Archive)
- 8 блоков внутри Areas (Self, Relationships, Work, Finance, Environment, Energy, Creation, World)

Все блоки создаются с:
- Правильными `layoutCells` для отображения в сетке
- Цветами и стилями согласно дизайну
- Метаданными (`homePageRole`, `areaType`) для последующей обработки

## Ручное использование пресетов

### Создание начальной страницы вручную

1. Создать корневой блок "Home" (или использовать существующий)
2. Открыть Layout Editor (`l+e`)
3. Выбрать пресет "Home" в категории "Специальные"
4. Нажать "Создать блоки" для генерации 6 блоков
5. Применить раскладку

### Настройка Areas

1. Открыть блок "Areas"
2. Открыть Layout Editor (`l+e`)
3. Выбрать пресет "Areas" (2×4 сетка)
4. Нажать "Создать блоки" для генерации 8 областей
5. Блоки создадутся с названиями и цветами из шаблона

## Планируемые фичи

### Авторотация ссылок (для Focus)

```javascript
// Типы авторотации
const AUTOROTATE_RULES = {
    currentWeek: 'Текущая неделя',
    currentMonth: 'Текущий месяц',
    today: 'Сегодня',
    nextMeeting: 'Ближайшая встреча'
};

// Формат хранения
{
    type: 'link',
    autorotate: {
        rule: 'currentWeek',
        sourceBlockId: 'calendar-2026-uuid'
    }
}
```
